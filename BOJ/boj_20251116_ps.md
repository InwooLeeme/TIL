### 1. [<span style="color: #ec9a00;">G3</span>] [Heights](https://www.acmicpc.net/problem/17236)

- **tag** : math, geometry

헤론의 정리를 쓰면 된다.

```cpp
using ld = long double;
ld ha, hb,hc;

void solve(){
	ri(ha, hb, hc);
	ld A = 1 / ha;
	ld B = 1 / hb;
	ld C = 1 / hc;
	ld S = A + B + C;
	ld area = 1 / sqrt(S * (S - A * 2) * (S - B * 2) * (S - C * 2));
	po(area);
}
```

### 2. [<span style="color: #435f7a;">S2</span>] [Triples](https://www.acmicpc.net/problem/10357)

- **tag** : math, number theory, bruteforce

페르마의 마지막 정리...를 이용하고 브루트포스를 돌려서 검증할 수 있다.

```cpp
int n,m,res;

void solve(){
	ri(n, m);
	for(int i = 0; i <= n; i++){
		for(int j = i; j <= n; j++){
			for(int k = j; k <= n; k++){
				if(i * i + j * j == k * k) res++;
			}
		}
	}
	po(res + (m - 2)*(n + 1));
}
```

### 3. [<span style="color: #ec9a00;">G3</span>] [약수게임](https://www.acmicpc.net/problem/16894)

- **tag** : math, number theory, game_theory, primality_test

주어지는 수가 소수이거나, 1이면 선공이 이긴다.
그게 아니라면 전체 인수의 개수가 2가 아니라면 선공이 이긴다.

```cpp
int n;

void solve(){
	ri(n);
	if(n == 1){
		po("koosaga");
		return;
	}
	vi res;
	for(int i = 2; i *i <= n; i++){
		while(n % i == 0) n /= i, res.pb(i);
	}
	if(n > 1) res.pb(n);
	if(si(res) != 2) po("koosaga");
	else po("cubelover");
}
```

### 5. [<span style="color: #ec9a00;">G5</span>] [최대 합 순서쌍의 개수](https://www.acmicpc.net/problem/30646)

- **tag** : data_structures, set, prefix_sum, hash_set

각 수의 인덱스를 맵으로 관리하자.
그리고 누적합을 이용해서 각 수의 인덱스를 보면서 최대값과 빈도를 검사하면 된다.

```cpp
int n;
map<int, vi> M;

void solve(){
	ri(n);
	vi v(n + 1);
	for(int i = 1; i <= n; i++){
		ri(v[i]);
		M[v[i]].pb(i);
		v[i] += v[i - 1];
	}
	int mx = 0, cnt = 1;
	for(const auto& [a, b] : M){
		int L = *b.begin(),R = *prev(b.end());
		int S = v[R] - v[L - 1];
		if(S > mx) mx = S,cnt = 1;
		else if(S == mx) cnt++;
	}
	po(mx, cnt);
}
```

### 6. [<span style="color: #ec9a00;">G4</span>] [수열의 점수](https://www.acmicpc.net/problem/2036)

- **tag** : greedy, sorting

웰노운 그리디다.
중요한건 음수, 양수, 0, 1을 각각 나눠서 봐야한다
수가 1인 경우 무조건 각자 더하는게 이득이다.
음수와 1 이상의 양수인 경우 2개씩 묶어서 더하는게 이득이고 음수인 경우는 minpq, 1이상의 양수인 경우엔 maxpq로 구현하면 된다.
0인 경우 음수를 2개씩 묶고 난 이후의 값들과 묶어서 처리해주면 된다.

```cpp
ll n,res;

void solve(){
	ri(n);
	minpq<ll> mi;
	maxpq<ll> pl;
	for(int i = 0; i < n; i++){
		int x; ri(x);
		if(x == 1) res += x;
		else{
			if(x > 1) pl.push(x);
			else if(x <= 0) mi.push(x);
		}
	}
	while(si(pl) > 1){
		auto a = pl.top(); pl.pop();
		auto b = pl.top(); pl.pop();
		res += (a * b);
	}
	while(si(mi) > 1){
		auto a = mi.top(); mi.pop();
		auto b = mi.top(); mi.pop();
		res += (a * b);
	}
	while(!mi.empty()){
		res += mi.top(); mi.pop();
	}
	while(!pl.empty()){
		res += pl.top(); pl.pop();
	}
	po(res);
}
```
